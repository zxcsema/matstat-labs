# mathstat-labs

Пять работ по математической статистике: первичное описание выборок с оценками параметров методом моментов и максимального правдоподобия, проверка гипотез по четырем столбцам (t-критерий, Манна-Уитни, хи-квадрат Пирсона), сравнение средних двух независимых выборок, парная регрессия с доверительными интервалами и сравнение трех моделей на данных по процессорам Intel.

Считал по формулам через numpy и scipy.stats, без statsmodels, чтобы было видно каждый шаг. Выборки лежат в data/, кроме одной - она маленькая и вписана прямо в ноутбук списком.

Часть работ делали в группе, здесь моя часть - расчеты и код.
